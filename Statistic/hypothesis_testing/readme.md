2.)  Больница хочет определить, существует ли разница в среднем времени выполнения результатов анализа лабораторий, входящих в их предпочтительный список. Для этого была собрана случайная выборка, и было зафиксировано время выполнения результатов анализа для 4 лабораторий. TAT определяется как время от момента взятия образца до отправки результатов анализа. Проанализируйте данные и определите, существует ли разница в среднем TAT между различными лабораториями на уровне значимости 5%.
